## ข้อสรุป
- การแปลงทั้งเกมไปมือถือเป็นงานหลายเดือนและต้องเขียนเรนเดอร์ใหม่ (D3D9 ไป bgfx/GLES ตามเฟส 3) และเครือข่ายใหม่ทั้งหมด
- เซิร์ฟเวอร์ต้องเปลี่ยนจาก Windows IOCP และ ODBC/SQL Server ไปเป็นระบบที่รันบนมือถือได้ (เช่น SQLite และ Python/C++ บน Linux) ซึ่งเป็นงานแยกที่ใหญ่ที่สุดของเซิร์ฟเวอร์
- ไบนารีของระบบป้องกันโกง (GameGuard) และการเข้ารหัสที่อยู่ในรีโปจะไม่นำมาใช้ ตามเอกสาร `LICENSE_RISKS.md`
- เงื่อนไขสิทธิ์: ผู้ใช้ระบุว่ามีสิทธิ์ ยังไม่ได้ตรวจเอกสาร ซอร์สยังมีลิขสิทธิ์ของ Min Communications, Inc

## ลำดับที่แนะนำ (ทำทีละขั้นและมีเทสต์ผ่าน)
1. เซิร์ฟเวอร์ล็อกอินและตัวละคร บนฐาน `ran_mobile/Server` ที่มีอยู่แล้ว (ทำไปแล้วส่วนใหญ่)
2. ตรรกะการต่อสู้และมอนสเตอร์ จากซอร์ส `GLogicText` และ `RanClientLib` ที่ไม่มี Windows API (ยังต้องคัดแยก)
3. แอปไคลเอนต์ Android ต่อกับเซิร์ฟเวอร์ (ต้องเพิ่ม HTTP ใน C++)
4. เรนเดอร์ด้วย GLES ตามเฟส 3 เฉพาะฉากที่ใช้ได้จริง
