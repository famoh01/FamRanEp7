# ความเสี่ยงด้านลิขสิทธิ์และความปลอดภัย

> เอกสารนี้ไม่ใช่คำแนะนำทางกฎหมาย ต้องให้ผู้เชี่ยวชาญตรวจก่อนเผยแพร่

## 1. ลิขสิทธิ์ซอร์สและแอสเซ็ต

- README ของ `ran-online-ep7` ระบุว่าซอร์ส "เป็นลิขสิทธิ์ของ Min Communications, Inc และนักพัฒนาที่เกี่ยวข้อง" และแจกเพื่อการศึกษา ผู้ใช้ต้องรับความเสี่ยงเองหากทำเซิร์ฟเวอร์เอกชน
- README ของซอร์สยังระบุว่าอ้างอิงจาก "EP7 shared by Jollin88" ซึ่งเป็นแหล่งที่มาที่ยังไม่ได้ตรวจสอบ
- แอสเซ็ตจาก release (ไคลเอนต์ภาษาไทย 2.5 GB, ServerDBTools, ThaiPack) เป็นของเจ้าของเกมเช่นกัน
- **ก่อนแจกหรือเผยแพร่ APK ต้องมีหลักฐานสิทธิ์ใช้งานที่ชัดเจน** ซึ่งยังไม่มี

## 2. ไลบรารีภายนอกในซอร์ส

- `=Library/ggauth.dll`, `ggsrvdll.dll`, `NPGameLib` เป็นระบบป้องกันโกงของบุคคลที่สาม ต้องตรวจไลเซนส์ก่อนแจกต่อ
- `=boost`, `=ZLIB`, `=TbbLib`, `Vorbislib` มีไลเซนส์โอเพนซอร์ส ต้องเก็บไฟล์ไลเซนส์และใส่ใน `THIRD_PARTY_NOTICES.md` เมื่อนำไปใช้
- `=MAX*SDK` เป็น SDK ของ Autodesk ไม่เกี่ยวกับตัวเกมมือถือ ควรไม่รวมในผลิตภัณฑ์

## 3. ระบบป้องกันโกง (GameGuard)

- อ้างถึงใน 33 ไฟล์ของซอร์ส
- Phase 6 ในชุดคำสั่งสั่งให้ลบ "โมดูลป้องกันที่เป็น Windows-only" ซึ่งอาจหมายถึงระบบนี้
- **ถ้าลบออกแล้วเซิร์ฟเวอร์ที่มีผู้เล่นจริงจะโกงได้ง่ายขึ้น** ไม่ควรลบเองโดยไม่ได้ตกลงกับผู้ดูแลเซิร์ฟเวอร์
- ทางเลือกที่ปลอดภัยกว่า: เก็บไว้จนถึงการตัดสินใจ หรือใช้การตรวจสอบฝั่งเซิร์ฟเวอร์แทน

## 4. ความปลอดภัยของเซิร์ฟเวอร์

- ตามคำสั่งเฟส 7: เซิร์ฟเวอร์ต้องเป็นผู้ตัดสินสุดท้ายเสมอ (server-authoritative)
- ห้ามฝังรหัสผ่านฐานข้อมูลหรือ IP จริงในโค้ด ใช้ไฟล์ config ที่ไม่เข้า git
- ห้ามเปิดพอร์ตฐานข้อมูลสู่อินเทอร์เน็ต
